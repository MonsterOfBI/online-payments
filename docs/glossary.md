# Глоссарий (своими словами)
| Термин | Что это |
|---|---|
| Эквайринг | Приём оплаты картами: банк-эквайрер проводит платёж и перечисляет деньги магазину |
| Платёжный сервис (агрегатор) | Компания, которая даёт магазину один API для карт, СБП, кошельков (здесь ЮKassa) |
| СБП, C2B | Система быстрых платежей; C2B — оплата покупателем бизнеса (по QR или ссылке) |
| НСПК | Операционный центр СБП и платёжной системы «Мир» |
| Цифровой рубль | Третья форма рубля, кошельки на платформе Банка России, доступ через банк |
| 3-DS (3-D Secure) | Подтверждение платежа картой кодом из SMS или приложения банка |
| Webhook | Уведомление: сервис сам вызывает наш URL, когда что-то произошло |
| Polling (опрос) | Мы сами периодически спрашиваем статус |
| Идемпотентность | Повтор того же запроса не создаёт второй результат |
| Одно- / двухстадийная оплата | Сразу списать / сначала заморозить, потом подтвердить (capture) или отменить |
| Чек 54-ФЗ, ОФД | Кассовый чек по закону о ККТ; ОФД передаёт его в ФНС |
| Chargeback | Оспаривание покупателем платежа через свой банк |
| Конверсия оплаты | Доля заказов, которые успешно оплачены |
| p95 | 95 % значений меньше этого числа — так видно «хвост» долгих случаев |
| ADR | Короткая запись архитектурного решения: контекст, варианты, выбор, минусы |
| OpenAPI | Стандарт описания REST API в YAML/JSON |
| Коды 201 / 409 / 422 | Создано / конфликт с текущим состоянием / данные понятны, но нарушают правила |
